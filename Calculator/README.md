# 🧮 Simple Python Calculator

A simple command-line calculator built using Python. This project performs basic arithmetic operations and allows
users to continue calculations with the previous result, start a new calculation, or exit the program.

---
## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Continue calculations using the previous result
- 🆕 Start a new calculation
- 🚪 Exit the program
- ✅ Basic input validation for menu choices

---

This project was built to practice and improve understanding of:

- Functions
- Function Parameters
- Conditional Statements (`if`, `elif`, `else`)
- Recursion
- User Input Handling
- Arithmetic Operations
- Program Flow Control

---

## 🚀 How It Works

1. Enter the first number.
2. Select an operator (`+`, `-`, `*`, `/`).
3. Enter the second number.
4. View the result.
5. Choose one of the following options:
   - `y` → Continue calculation with the current result.
   - `n` → Start a new calculation.
   - `x` → Exit the program.

---

## 💻 Example

```text
Enter the first number : 10
Enter the operator :
+
-
*
/

+
Enter the next number : 5

10 + 5 = 15

Continue(y) | New(n) | Exit(x):
Enter the choice : y

Enter the next number : 3
Enter the operator : *

15 * 3 = 45
```
